# SVBONY_SV205_ASCOM_DRIVER
SV205 Synthetic Mono ASCOM driver for Windows/PHD2. Provides experimental grayscale/luma capture, time-based stacking, guiding presets, hot-pixel/dark-frame options, and SVBONY SV205 camera selection for low-cost astrophotography guiding tests.
